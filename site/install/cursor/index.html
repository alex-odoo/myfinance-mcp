Install guide · Cursor

Expense tracker for Cursor, set up in a minute

One click adds MyFinance to Cursor. Then the Agent chat logs what you spent, imports statements from any bank and answers budget questions, next to your code.

Server URL: https://myfinance-mcp.com/mcp

Add to Cursor Manual setup
Setup

Five steps, about a minute

  1. Click Add to Cursor above; the link opens Cursor, which asks to install the MyFinance MCP server
  2. Confirm the install prompt in Cursor
  3. Open Customize in the sidebar, find MyFinance under MCP servers and click Connect
  4. Sign in with Google or an email code in the browser window that opens, then return to Cursor
  5. Ask in the Agent chat, for example: log 12 EUR for lunch in MyFinance

Cursor asks for approval before each MCP tool call by default. If the button does nothing, the direct cursor:// link opens the same install prompt.

Manual setup: add MyFinance to ~/.cursor/mcp.json for every project, or to .cursor/mcp.json in one project, then sign in as in steps 3 and 4.

{
  "mcpServers": {
    "myfinance": {
      "url": "https://myfinance-mcp.com/mcp"
    }
  }
}
Sign-in

What the sign-in screen looks like

When Cursor connects, a MyFinance MCP page opens on myfinance-mcp.com. It names the client you are connecting and where you return afterwards: "an app on this device" (that is Cursor). There is no separate MyFinance website login; this page is the only one you will see.

  1. Continue with Google: one click if you use a Google account.
  2. Or type any email address and click Email me a sign-in code. We send an 8-digit code that expires in 10 minutes; enter it and click Sign in. No Google account needed.
  3. The first sign-in creates your account. Next time, the same Google account or email brings back the same data.

First things to say

Five messages that pay off fast

Start with your currency and city, so every amount and date lands right. Then log, import, ask and set one budget. Use your own currency and shops: these are examples, typed into Cursor as plain messages.

01 "My currency is ARS and I live in Buenos Aires" base currency ARS · timezone set
02 "I spent 12,500 on groceries at Coto yesterday and 4,000 on a taxi today" 2 expenses · groceries, transport · dates resolved
03 [screenshot] "Here is my bank statement" every row imported · duplicates skipped
04 "How much did I spend this month by category?" totals by category · computed in SQL
05 "Set a monthly budget of 80,000 for entertainment" 80,000 ARS cap · alerts only when exceeded

Every total comes from the server, computed in SQL. Cursor explains the numbers; it never adds them up itself.

Troubleshooting

If something is off

Connect does nothing

Click the Needs authentication line under the server name instead, or open the Output panel (Cmd+Shift+U on Mac, Ctrl+Shift+U on Windows and Linux), choose MCP Logs and open the sign-in link from there.

MyFinance shows no tools

Toggle MyFinance off and on in Customize, or remove it and add it again. MCP Logs in the Output panel shows the exact error.

The Add to Cursor button opened nothing

Install or update Cursor and try again, or use the manual mcp.json setup on this page. The button page also shows the config to copy.

Something broke after a MyFinance update

Toggle MyFinance off and on in Customize, or restart Cursor, so it reloads the tool list. If tools are still missing, remove the server and add it again.
