Install guide · Codex

Expense tracker for Codex, set up in a minute

Two commands connect MyFinance to OpenAI Codex. Codex is included in every ChatGPT plan, Free and Go too, so this is also the way to use MyFinance with a ChatGPT plan that has no custom MCP servers.

Server URL: https://myfinance-mcp.com/mcp

Setup

Five steps in the Codex CLI

  1. Install or update Codex and sign in with your ChatGPT account
  2. Add the server: codex mcp add myfinance --url https://myfinance-mcp.com/mcp
  3. Sign in: codex mcp login myfinance opens the MyFinance sign-in page in your browser
  4. Start codex and type /mcp to check that MyFinance is connected
  5. Ask, for example: log 12 EUR for lunch in MyFinance

The CLI, the Codex IDE extension and the ChatGPT desktop app share one configuration, ~/.codex/config.toml, so you set MyFinance up once.

In the Codex IDE extension (gear menu) or the ChatGPT desktop app (Settings): open MCP servers, click Add server, name it MyFinance, choose Streamable HTTP, paste the URL, save and restart, then click Authenticate. Or add this to ~/.codex/config.toml and run the login command:

[mcp_servers.myfinance]
url = "https://myfinance-mcp.com/mcp"
Sign-in

What the sign-in screen looks like

When Codex connects, a MyFinance MCP page opens on myfinance-mcp.com. It names the client you are connecting and where you return afterwards: "an app on this device" (that is Codex). There is no separate MyFinance website login; this page is the only one you will see.

  1. Continue with Google: one click if you use a Google account.
  2. Or type any email address and click Email me a sign-in code. We send an 8-digit code that expires in 10 minutes; enter it and click Sign in. No Google account needed.
  3. The first sign-in creates your account. Next time, the same Google account or email brings back the same data.

First things to say

Five messages that pay off fast

Start with your currency and city, so every amount and date lands right. Then log, import, ask and set one budget. Use your own currency and shops: these are examples, typed into Codex as plain messages.

01 "My currency is ARS and I live in Buenos Aires" base currency ARS · timezone set
02 "I spent 12,500 on groceries at Coto yesterday and 4,000 on a taxi today" 2 expenses · groceries, transport · dates resolved
03 [screenshot] "Here is my bank statement" every row imported · duplicates skipped
04 "How much did I spend this month by category?" totals by category · computed in SQL
05 "Set a monthly budget of 80,000 for entertainment" 80,000 ARS cap · alerts only when exceeded

Every total comes from the server, computed in SQL. Codex explains the numbers; it never adds them up itself.

Troubleshooting

If something is off

codex mcp login opens no browser

Copy the link Codex prints in the terminal into your browser. When the sign-in page says you return to an app on this device, that is Codex's local callback.

/mcp lists MyFinance without tools

Run codex mcp login myfinance again. If that does not help, run codex mcp remove myfinance, add the server again and log in.

Which ChatGPT plans include Codex?

Every one: OpenAI includes Codex in all ChatGPT plans, Free and Go too, with usage limits that depend on the plan. Using MyFinance through Codex needs no Developer mode.

Something broke after a MyFinance update

Restart Codex, or restart the IDE extension, so it reloads the tool list. If tools are still missing, run codex mcp login myfinance again.

Other clients

Using another AI?

The same server and the same account work in every client: sign in with the same Google account or email and your data is there.
