If you are not sure where to start

Use the AI you already open every day. Your data follows your sign-in, so you can add a second client later.

Quickest paths

  • On any Claude plan: the Claude guide, free plan included
  • On ChatGPT Business, Enterprise or Edu: the ChatGPT guide
  • On ChatGPT Free, Go, Plus or Pro: use Codex, included in your plan
  • Writing code in Cursor already: one click in the Cursor guide

The same everywhere

  • One account: sign in with the same Google account or email in every client and you see the same data
  • Every number is computed on the server in SQL, never guessed by the AI
  • Statements from any bank: CSV, PDF or a screenshot from your banking app
  • Free while in beta, open source under MIT
