Install guide · Claude

Expense tracker for Claude, set up in a minute

Add MyFinance as a custom connector and Claude becomes an expense tracker: say what you spent, drop a statement from any bank, ask for budgets and monthly summaries. Free, on every Claude plan.

Server URL: https://myfinance-mcp.com/mcp

Setup

Six steps, about a minute

  1. Open Claude on the web or in the desktop app and go to Customize, then Connectors
  2. Click + Add, then Add custom connector
  3. Name it MyFinance, paste https://myfinance-mcp.com/mcp as the remote MCP server URL and click Continue
  4. Under Authentication choose Sign in now; under OAuth client keep the default, Use Claude's published identity (Recommended). Register automatically works too
  5. Click Add, then sign in with Google or an email code
  6. In a chat, click +, then Connectors, and check that MyFinance is switched on
Never pick "Use your own OAuth client" and never fill a Client ID or Secret (older versions of the form show these fields: leave them empty). MyFinance recognises Claude by itself; your credentials go on the MyFinance sign-in page.

Custom connectors work on every Claude plan: Free, Pro, Max, Team and Enterprise. The Free plan allows one custom connector. On Team and Enterprise an Owner adds the connector for the organization first, then each member connects it from Customize, Connectors. The connector lives in your Claude account, so the desktop and mobile apps use it too.

Using Claude Code? Run claude mcp add --transport http myfinance https://myfinance-mcp.com/mcp, then type /mcp in Claude Code to sign in.

Sign-in

What the sign-in screen looks like

When Claude connects, a MyFinance MCP page opens on myfinance-mcp.com. It names the client you are connecting and where you return afterwards: claude.ai. There is no separate MyFinance website login; this page is the only one you will see.

  1. Continue with Google: one click if you use a Google account.
  2. Or type any email address and click Email me a sign-in code. We send an 8-digit code that expires in 10 minutes; enter it and click Sign in. No Google account needed.
  3. The first sign-in creates your account. Next time, the same Google account or email brings back the same data.

First things to say

Five messages that pay off fast

Start with your currency and city, so every amount and date lands right. Then log, import, ask and set one budget. Use your own currency and shops: these are examples, typed into Claude as plain messages.

01 "My currency is ARS and I live in Buenos Aires" base currency ARS · timezone set
02 "I spent 12,500 on groceries at Coto yesterday and 4,000 on a taxi today" 2 expenses · groceries, transport · dates resolved
03 [screenshot] "Here is my bank statement" every row imported · duplicates skipped
04 "How much did I spend this month by category?" totals by category · computed in SQL
05 "Set a monthly budget of 80,000 for entertainment" 80,000 ARS cap · alerts only when exceeded

Every total comes from the server, computed in SQL. Claude explains the numbers; it never adds them up itself.

Troubleshooting

If something is off

The connector shows no tools

Remove the connector (Customize, Connectors, the three dots next to MyFinance, Remove) and add it again with the same URL. Claude reads the tool list when you connect, so a fresh connection fixes most cases.

Sign-in fails right after I click Add

The connector was probably added with a different OAuth client option or with a Client ID filled in. Remove it and add it again with Sign in now and either Use Claude's published identity or Register automatically, leaving any Client ID and Secret fields empty. If the published identity option keeps failing, choose Register automatically.

Claude does not use MyFinance in a chat

Click + in the chat, then Connectors, and switch MyFinance on for that conversation. Then ask directly, for example: use MyFinance to log 20 EUR for lunch.

Something broke after a MyFinance update

Reconnect: remove MyFinance in Customize, Connectors and add it again with the same URL. Claude keeps the tool list from your last connection, so new or changed tools appear only after you reconnect. Your data stays: it is tied to your sign-in, not to the connector.

Other clients

Using another AI?

The same server and the same account work in every client: sign in with the same Google account or email and your data is there.
