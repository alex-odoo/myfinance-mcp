Install guide · ChatGPT

Expense tracker for ChatGPT, set up in a minute

Add MyFinance as a custom MCP app and ChatGPT logs your spending, imports statements from any bank and answers budget questions. Check your plan first: OpenAI limits custom MCP servers to some plans.

Server URL: https://myfinance-mcp.com/mcp

Plans

Which ChatGPT plans can use it

Custom MCP servers in ChatGPT run in Developer mode, on the web. Logging an expense is a write action, which OpenAI allows only on some plans.

Works for logging

  • ChatGPT Business: workspace admins and owners turn on Developer mode for themselves
  • ChatGPT Enterprise and Edu: an admin grants Developer mode, then you turn it on
  • Any ChatGPT plan, Free and Go included, through Codex

Limited or not available

  • ChatGPT Pro: read-only access, so MyFinance can answer from your data but not log
  • ChatGPT Free, Go and Plus: no custom MCP servers in the chat
  • ChatGPT mobile apps: custom MCP apps are web only

This follows OpenAI's help center article on Developer mode and MCP apps. On a plan without custom MCP servers, Codex (included in every ChatGPT plan) or Claude (one custom connector on its free plan) gets you the same tools.

Setup

Six steps on the web

  1. Turn on Developer mode: Settings, then Apps, then Advanced settings
  2. Open Plugins in the sidebar, click +, then Add custom MCP server (on the older menu: Settings, then Apps, then Create)
  3. Name it MyFinance and paste https://myfinance-mcp.com/mcp as the server URL
  4. Choose OAuth as authentication and leave the client ID and secret empty
  5. Review the risk warning, select I understand and want to continue, create the app and sign in with Google or an email code
  6. Start a new chat, type @ and pick MyFinance

Logging an expense is a write action, so ChatGPT asks you to confirm it; you can approve a tool once for the rest of the conversation. In a Business, Enterprise or Edu workspace an admin can publish the tested app for everyone.

Sign-in

What the sign-in screen looks like

When ChatGPT connects, a MyFinance MCP page opens on myfinance-mcp.com. It names the client you are connecting and where you return afterwards: chatgpt.com. There is no separate MyFinance website login; this page is the only one you will see.

  1. Continue with Google: one click if you use a Google account.
  2. Or type any email address and click Email me a sign-in code. We send an 8-digit code that expires in 10 minutes; enter it and click Sign in. No Google account needed.
  3. The first sign-in creates your account. Next time, the same Google account or email brings back the same data.

First things to say

Five messages that pay off fast

Start with your currency and city, so every amount and date lands right. Then log, import, ask and set one budget. Use your own currency and shops: these are examples, typed into ChatGPT as plain messages.

01 "My currency is ARS and I live in Buenos Aires" base currency ARS · timezone set
02 "I spent 12,500 on groceries at Coto yesterday and 4,000 on a taxi today" 2 expenses · groceries, transport · dates resolved
03 [screenshot] "Here is my bank statement" every row imported · duplicates skipped
04 "How much did I spend this month by category?" totals by category · computed in SQL
05 "Set a monthly budget of 80,000 for entertainment" 80,000 ARS cap · alerts only when exceeded

Every total comes from the server, computed in SQL. ChatGPT explains the numbers; it never adds them up itself.

Troubleshooting

If something is off

I don't see Developer mode or Add custom MCP server

Your plan or workspace does not allow custom MCP servers. On Business only admins and owners can use Developer mode; on Enterprise and Edu ask an admin to grant it. Free, Go and Plus do not have it: use Codex or Claude instead.

The app shows no tools

Open MyFinance under Plugins and select Refresh, or delete the app and add it again with the same URL. ChatGPT reads the tool list when the app is created.

MyFinance can read my data but cannot log anything

On ChatGPT Pro, OpenAI gives custom MCP servers read-only access. Logging needs Business, Enterprise or Edu, or another client such as Codex, Claude or Cursor. On those plans, approve the action when ChatGPT asks for confirmation.

Something broke after a MyFinance update

Open MyFinance under Plugins and select Refresh, or remove it and add it again. In a workspace an admin may have to refresh the published app's actions, because ChatGPT keeps the tool list it approved earlier.

Other clients

Using another AI?

The same server and the same account work in every client: sign in with the same Google account or email and your data is there.
