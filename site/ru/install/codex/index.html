Учёт расходов в Codex за минуту

Две команды подключают MyFinance к OpenAI Codex. Codex входит во все тарифы ChatGPT, включая Free и Go, так что это ещё и способ пользоваться MyFinance на тарифе ChatGPT без пользовательских MCP-серверов.

Адрес сервера: https://myfinance-mcp.com/mcp

Показать команды Что сказать сначала
Настройка

Пять шагов в Codex CLI

  1. Установите или обновите Codex и войдите с аккаунтом ChatGPT
  2. Добавьте сервер: codex mcp add myfinance --url https://myfinance-mcp.com/mcp
  3. Войдите: codex mcp login myfinance откроет страницу входа MyFinance в браузере
  4. Запустите codex и введите /mcp, чтобы проверить, что MyFinance подключён
  5. Задайте вопрос, например: запиши в MyFinance 12 EUR за обед

CLI, расширение Codex для IDE и десктопное приложение ChatGPT используют одну конфигурацию, ~/.codex/config.toml, так что MyFinance настраивается один раз.

В расширении Codex для IDE (меню с шестерёнкой) или в десктопном приложении ChatGPT (Settings): откройте MCP servers, нажмите Add server, назовите его MyFinance, выберите Streamable HTTP, вставьте URL, сохраните и перезапустите, затем нажмите Authenticate. Или добавьте это в ~/.codex/config.toml и выполните команду входа:

[mcp_servers.myfinance]
url = "https://myfinance-mcp.com/mcp"
Вход

Как выглядит страница входа

Когда Codex подключается, открывается страница MyFinance MCP на myfinance-mcp.com, на английском. На ней указано, какой клиент вы подключаете и куда вернётесь после входа: «an app on this device» (приложение на этом устройстве, то есть Codex). Отдельного входа на сайте MyFinance нет; это единственная страница, которую вы увидите.

  1. Continue with Google (продолжить с Google): один клик, если у вас есть аккаунт Google.
  2. Или введите любой адрес почты и нажмите Email me a sign-in code (прислать код). Мы отправим 8-значный код, который действует 10 минут; введите его и нажмите Sign in. Аккаунт Google не нужен.
  3. Первый вход создаёт аккаунт. В следующий раз тот же аккаунт Google или та же почта вернут те же данные.

Что сказать сначала

Пять сообщений, которые сразу окупаются

Начните с валюты и города, чтобы все суммы и даты легли правильно. Затем запишите расход, импортируйте выписку, задайте вопрос и поставьте один бюджет. Подставьте свою валюту и свои магазины: это примеры, которые пишут в Codex обычными сообщениями.

01 «Моя валюта рубли, я живу в Москве» базовая валюта RUB · часовой пояс задан
02 «Вчера потратил 3 400 на продукты в Пятёрочке, а сегодня 900 на такси» 2 расхода · продукты, транспорт · даты определены
03 [скриншот] «Вот моя банковская выписка» все строки импортированы · дубли пропущены
04 «Сколько я потратил в этом месяце по категориям?» итоги по категориям · посчитано в SQL
05 «Поставь месячный бюджет 15 000 на развлечения» лимит 15 000 RUB · уведомления только при превышении

Все итоги приходят с сервера и посчитаны в SQL. Codex объясняет цифры, но никогда не складывает их сам.

Решение проблем

Если что-то не так

codex mcp login не открывает браузер

Скопируйте в браузер ссылку, которую Codex выводит в терминале. Если страница входа пишет, что вы вернётесь в an app on this device, это локальный callback Codex.

/mcp показывает MyFinance без инструментов

Снова выполните codex mcp login myfinance. Если не помогло, выполните codex mcp remove myfinance, добавьте сервер заново и войдите.

Какие тарифы ChatGPT включают Codex?

Все: OpenAI включает Codex во все тарифы ChatGPT, включая Free и Go, с лимитами использования в зависимости от тарифа. Для MyFinance через Codex Developer mode не нужен.

Что-то сломалось после обновления MyFinance

Перезапустите Codex или расширение для IDE, чтобы он перечитал список инструментов. Если инструментов всё ещё нет, снова выполните codex mcp login myfinance.

Другие клиенты

Пользуетесь другим ИИ?

Тот же сервер и тот же аккаунт работают в любом клиенте: войдите с тем же аккаунтом Google или той же почтой, и ваши данные на месте.

инструкция

Claude →

Customize, Connectors, Add custom connector. Любой тариф Claude, включая Free.

 инструкция

ChatGPT →

Developer mode в веб-версии. Запись расходов на Business, Enterprise и Edu.

 инструкция

Cursor →

Добавить в Cursor в один клик или три строки в mcp.json.

Windsurf, VS Code, Claude Code и любой MCP-клиент с OAuth тоже работают: смотрите все инструкции по установке.
