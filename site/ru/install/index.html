Подключите MyFinance к своему ИИ

MyFinance MCP: бесплатный учёт расходов с ИИ прямо внутри того ИИ, которым вы уже пользуетесь. Один URL сервера, один вход через Google или по коду из письма, около минуты. Выберите свой клиент, чтобы увидеть точные шаги, пять первых фраз и решения типичных проблем.

Адрес сервера: https://myfinance-mcp.com/mcp

Выберите клиент

Пошаговые инструкции

В каждой инструкции: точные шаги, как выглядит страница входа, пять первых сообщений и решения типичных проблем.

 инструкция

 инструкция

Добавить в Cursor в один клик или три строки в mcp.json. Вход один раз из Customize.

 инструкция

codex mcp add, затем codex mcp login. Входит во все тарифы ChatGPT, включая Free.

Windsurf, VS Code, Claude Code или другой MCP-клиент с OAuth 2.0 и PKCE? На вкладке «Другие» на главной есть JSON-конфиг и команда для Claude Code.

Что выбрать?

Если не знаете, с чего начать

Используйте тот ИИ, который и так открываете каждый день. Данные привязаны к вашему входу, так что второй клиент можно добавить позже.

Самые быстрые пути

  • На любом тарифе Claude: инструкция для Claude, бесплатный тариф тоже подходит
  • На ChatGPT Business, Enterprise или Edu: инструкция для ChatGPT
  • На ChatGPT Free, Go, Plus или Pro: используйте Codex, он входит в ваш тариф
  • Уже пишете код в Cursor: один клик в инструкции для Cursor

Везде одинаково

  • Один аккаунт: войдите с тем же аккаунтом Google или той же почтой в любом клиенте и увидите те же данные
  • Каждое число считается на сервере в SQL, ИИ его не угадывает
  • Выписки любого банка: CSV, PDF или скриншот из банковского приложения
  • Бесплатно, пока идёт бета, открытый код под лицензией MIT

Обновлено: 14 октября 2026 г. Claude, ChatGPT, Codex и Cursor являются товарными знаками их владельцев. MyFinance MCP является независимым проектом с открытым кодом, не связан с ними и не одобрен ими.
