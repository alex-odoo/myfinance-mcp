Как это работает

Три шага. Никаких приложений.

Работает сразу после подключения. В первом разговоре ИИ сам настроит базовую валюту и часовой пояс и будет отвечать вам по-русски; сам MyFinance (страница входа, панели в чате и письма) на английском.

Шаг 1 / 3

Подключите один раз.

Работает с любым ИИ-клиентом, который поддерживает удалённые MCP-серверы: Claude, ChatGPT, Codex, Cursor и другими. Ничего не нужно устанавливать, никаких API-ключей.

Шаг 2 / 3

Просто скажите, сколько потратили.

Обычными словами, фото чека или целой выпиской из любого банка. Категории, валюты и дубликаты обрабатываются автоматически.

Шаг 3 / 3

Спрашивайте что угодно.

Сводки за месяц, тренды, бюджеты, капитал. Каждое число считается в SQL на сервере. ИИ читает расчёты и никогда их не угадывает.

Любой банк · импорт выписок

Работает с любым банком. Просто перетащите выписку.

Выгрузите CSV или PDF из банка или сделайте скриншот в банковском приложении и перетащите его в чат. ИИ прочитает выписку, сервер импортирует каждую строку, пропустит то, что уже есть, и сверит результат с итогом выписки.

любой банк

CSV, PDF или скриншот

Любой банк умеет выгружать выписку, в любой стране и в любой валюте. Сотни строк загружаются одним сообщением, каждая в той валюте, в которой была оплата.

без дублей

Дубли пропускаются, ваши правки остаются

Строки, которые вы уже внесли вручную, объединяются, а не дублируются, и сохраняют вашу категорию. Перетащить ту же выписку дважды безопасно: уже импортированные строки пропускаются, и об этом сообщается.

сверено

Сверено с выпиской

Каждый импорт заканчивается итогом, посчитанным в SQL и сверенным с итогом в выписке, так что неверно прочитанная строка всплывает сразу, а не через несколько месяцев.

Пользуетесь ZenMoney (популярен в Украине, России, Казахстане и Беларуси)? Один раз вставьте в чат бесплатный токен API ZenMoney, и ваши счета и операции синхронизируются в режиме только для чтения, с сохранением ваших правок.

Быстрая установка

Подключение меньше чем за минуту

Работает с любым MCP-клиентом, который поддерживает OAuth 2.0 с PKCE. Вы входите один раз при подключении: через Google или по одноразовому коду, который придёт на почту. Отдельного входа на сайте нет: ваш ИИ и есть приложение. Нужно подробнее? Смотрите пошаговые инструкции по установке.

  1. Откройте Claude и перейдите в Customize (Настроить), затем в Connectors (Коннекторы)
  2. Нажмите + Add, затем Add custom connector (добавить свой коннектор)
  3. Назовите его «MyFinance», вставьте https://myfinance-mcp.com/mcp как адрес удалённого MCP-сервера и нажмите Continue
  4. Выберите Sign in now; если форма спрашивает OAuth client, оставьте Use Claude's published identity (Recommended) (Register automatically тоже подойдёт)
  5. Нажмите Add и войдите через Google или по коду из письма
Никогда не выбирайте «Use your own OAuth client» и не заполняйте Client ID или Secret: это ломает вход. MyFinance сам распознаёт Claude, а ваши данные для входа вводятся на странице входа MyFinance.

Работает на всех тарифах Claude; на Free можно добавить один свой коннектор. Полная инструкция для Claude с первыми сообщениями и решением проблем.

  1. Включите Developer mode (режим разработчика): Settings, затем Apps, затем Advanced settings
  2. Откройте Plugins, нажмите +, затем Add custom MCP server (в старом меню: Settings, Apps, Create)
  3. Назовите его «MyFinance» и вставьте https://myfinance-mcp.com/mcp как адрес сервера
  4. Выберите OAuth для аутентификации, client ID и secret оставьте пустыми
  5. Примите предупреждение о рисках, создайте приложение и войдите
  6. В новом чате введите @ и выберите MyFinance
ChatGPT нужен Developer mode в веб-версии. Записывать расходы можно на Business, Enterprise и Edu; на Pro доступ только на чтение. OpenAI не указывает Developer mode для Free, Go и Plus: если вы его не видите, используйте Codex (входит во все тарифы ChatGPT) или Claude.

Только в веб-версии, не в мобильных приложениях ChatGPT. Полная инструкция для ChatGPT с тарифами и решением проблем.

Добавить в Cursor

  1. Нажмите Добавить в Cursor и подтвердите установку в Cursor
  2. Откройте Customize на боковой панели, найдите MyFinance в разделе MCP servers и нажмите Connect
  3. Войдите через Google или по коду из письма, затем задайте вопрос в чате Agent

Полная инструкция для Cursor с первыми сообщениями и решением проблем.

codex mcp add myfinance \
  --url https://myfinance-mcp.com/mcp
codex mcp login myfinance

Вторая команда откроет страницу входа MyFinance в браузере. Затем запустите codex и введите /mcp, чтобы проверить подключение. В расширении Codex для IDE или в десктопном приложении ChatGPT: MCP servers, затем Add server, Streamable HTTP, тот же URL, затем Authenticate. Codex входит во все тарифы ChatGPT, включая Free и Go. В Claude Code: claude mcp add --transport http myfinance https://myfinance-mcp.com/mcp
В Windsurf вместо url используется serverUrl. Вход по OAuth клиент выполнит автоматически.

Безопасность

Финансовый уровень защиты заложен в устройство, а не в значок.

без хранения фото

Чеки не покидают чат

Ваш ИИ разбирает фото в чате; сервер получает только структурированные числа. Хранилища изображений, которое можно взломать, просто нет.

данные в ес

Данные хранятся в ЕС

Postgres во Франкфурте, подключение по TLS. Сервер ограничивает каждый запрос вашим аккаунтом, а API базы данных закрыт для всех.

слепые логи

Слепые логи

Суммы, магазины и заметки никогда не пишутся в логи сервера. События использования хранят названия инструментов, время выполнения и коды ошибок, но не суммы и не магазины.

oauth 2.0 + pkce

Стандартная авторизация

OAuth 2.0 с PKCE и ограничением попыток входа. Токены хранятся только в виде одностороннего хеша; refresh-токены меняются при каждом использовании, а повторное предъявление уже использованного токена отзывает весь вход.

Вопросы

Вопросы и ответы

Коротко. Подробно на странице конфиденциальности (на английском).

Что такое MyFinance MCP?

Бесплатный учёт расходов с ИИ, работающий как сервер Model Context Protocol. Вы ведёте расходы, доходы, бюджеты и капитал, разговаривая с Claude, ChatGPT, Codex или Cursor: говорите ИИ, сколько потратили, он всё записывает, а сервер считает.

Что такое Model Context Protocol (MCP)?

Открытый стандарт, который позволяет ИИ-ассистентам подключаться к внешним инструментам. MCP-сервер даёт конкретные возможности, здесь учёт личных финансов, которыми ИИ пользуется во время разговора. Это как система плагинов для ИИ-ассистентов.

Работает ли с ChatGPT?

Да, в веб-версии ChatGPT с включённым Developer mode. Полная поддержка, включая запись расходов, есть в ChatGPT Business, Enterprise и Edu. На Pro OpenAI даёт пользовательским MCP-серверам доступ только на чтение; в справке OpenAI Developer mode не указан для Free, Go и Plus, так что если вы его там не видите, используйте Codex (входит во все тарифы ChatGPT). На любом тарифе ChatGPT, включая Free, MyFinance можно использовать через Codex. Оба варианта настройки описаны в инструкции для ChatGPT.

Какие клиенты поддерживаются?

Любой MCP-клиент с OAuth 2.0 + PKCE: Claude (веб, десктоп и мобильные приложения), Claude Code, ChatGPT (Business, Enterprise и Edu, в веб-версии), Codex, Cursor, Windsurf и VS Code. Для каждого есть пошаговая инструкция на странице установки.

Нужен ли аккаунт Google?

Нет. При подключении войдите через Google или по одноразовому коду, отправленному на любой адрес почты; первый вход создаёт аккаунт.

Это бесплатно?

Да, бесплатно, пока идёт бета. Без рекламы, без карты.

Мои данные приватны?

Ваши данные привязаны к вашему аккаунту, и доступ к ним есть только у вас. Хранение в ЕС, никакой передачи третьим лицам, никаких сумм в логах, токены входа хранятся только как односторонний хеш, а выгрузить (операции в CSV, остальной профиль одним файлом) или удалить всё можно в любой момент.

Может ли он читать мой банковский счёт?

Ему это не нужно: он работает с любым банком через импорт выписок. Выгрузите CSV или PDF или сделайте скриншот в банковском приложении и перетащите в чат. ИИ прочитает выписку, сервер импортирует каждую строку, пропустит дубликаты и сверит итог с выпиской. Пользователи ZenMoney могут подключить ZenMoney для синхронизации только на чтение. Прямая синхронизация с банками ЕС и Великобритании через лицензированный open banking находится в закрытой бете, только по приглашениям.

А что с дубликатами при импорте выписки?

Импорт находит строки, которые вы уже внесли вручную, и объединяет их, а не дублирует, а повторный импорт той же выписки безопасен: уже импортированные строки пропускаются, и об этом сообщается.

Можно разделить личное и бизнес?

Да. У счетов и отдельных операций есть пометка личное/бизнес; любой отчёт можно отфильтровать по ней, а выгрузка в CSV включает её для вашего бухгалтера.

Можно развернуть у себя?

Да. Лицензия MIT, запускается из Dockerfile с вашим собственным Postgres (Supabase подходит). В репозитории на GitHub есть инструкция по самостоятельному развёртыванию.
