Cómo funciona

Tres pasos. Ninguna app que aprender.

Funciona en cuanto te conectas. Tu IA configura tu moneda base y tu zona horaria en la primera conversación, y te responde en español; MyFinance en sí (la página de inicio de sesión, los paneles en el chat y los correos) está en inglés.

Paso 1 / 3

Conéctalo una vez.

Funciona con cualquier cliente de IA compatible con servidores MCP remotos: Claude, ChatGPT, Codex, Cursor y más. Sin instalar nada, sin claves de API.

Paso 2 / 3

Solo di lo que gastaste.

En lenguaje natural, con la foto de un ticket o con un extracto completo de cualquier banco. Categorías, monedas y duplicados se resuelven solos.

Paso 3 / 3

Pregunta lo que quieras.

Resúmenes mensuales, tendencias, presupuestos, patrimonio neto. Cada número se calcula en SQL en el servidor. La IA lee las cuentas, nunca las adivina.

Cualquier banco · importación de extractos

Funciona con cualquier banco. Solo arrastra el extracto.

Exporta un CSV o un PDF de tu banco, o haz una captura de pantalla en la app del banco, y arrástralo al chat. Tu IA lo lee, el servidor importa cada fila, omite lo que ya tienes y compara el resultado con el total del extracto.

cualquier banco

CSV, PDF o una captura

Todos los bancos permiten exportar un extracto, en cualquier país y en cualquier moneda. Cientos de filas entran con un solo mensaje, cada una en la moneda en que se pagó.

sin dobles

Duplicados omitidos, tus cambios intactos

Las filas que ya registraste a mano se fusionan, no se duplican, y conservan tu categoría. Arrastrar el mismo extracto dos veces es seguro: las filas ya importadas se omiten y se informan.

conciliado

Comparado con el extracto

Cada importación termina con un total calculado en SQL y comparado con el que figura en el extracto, así una fila mal leída aparece ahora y no meses después.

¿Usas ZenMoney (popular en Ucrania, Rusia, Kazajistán y Bielorrusia)? Pega una vez en el chat tu token gratuito de la API de ZenMoney y tus cuentas y transacciones se sincronizan, en modo de solo lectura, conservando tus cambios.

Instalación rápida

Conéctalo en menos de un minuto

Funciona con cualquier cliente MCP compatible con OAuth 2.0 con PKCE. Inicias sesión una vez al conectar, con Google o con un código de un solo uso enviado a tu correo. No hay un login web aparte: tu IA es la app. ¿Quieres más detalle? Mira las guías de instalación paso a paso.

  1. Abre Claude y ve a Customize (Personalizar) y luego a Connectors (Conectores)
  2. Haz clic en + Add y luego en Add custom connector (agregar conector personalizado)
  3. Ponle de nombre "MyFinance", pega https://myfinance-mcp.com/mcp como URL del servidor MCP remoto y haz clic en Continue
  4. Elige Sign in now; si el formulario pide un OAuth client, deja Use Claude's published identity (Recommended) (Register automatically también funciona)
  5. Haz clic en Add e inicia sesión con Google o con un código por correo
Nunca elijas "Use your own OAuth client" ni completes un Client ID o un Secret: eso rompe el inicio de sesión. MyFinance reconoce a Claude por sí solo, y tus credenciales van en la página de inicio de sesión de MyFinance.

Funciona en todos los planes de Claude; el plan Free permite un conector personalizado. Guía completa para Claude con primeros mensajes y soluciones.

  1. Activa Developer mode (modo de desarrollador): Settings, luego Apps, luego Advanced settings
  2. Abre Plugins, haz clic en + y luego en Add custom MCP server (en el menú anterior: Settings, Apps, Create)
  3. Ponle de nombre "MyFinance" y pega https://myfinance-mcp.com/mcp como URL del servidor
  4. Elige OAuth como autenticación y deja vacíos el client ID y el secret
  5. Acepta la advertencia de riesgo, créalo e inicia sesión
  6. En un chat nuevo, escribe @ y elige MyFinance
ChatGPT necesita Developer mode en la web. Registrar gastos funciona en Business, Enterprise y Edu; Pro tiene acceso de solo lectura. OpenAI no menciona Developer mode para Free, Go ni Plus: si no lo ves, usa Codex (incluido en todos los planes de ChatGPT) o Claude.

Solo en la web, no en las apps móviles de ChatGPT. Guía completa para ChatGPT con detalles de planes y soluciones.

Agregar a Cursor

  1. Haz clic en Agregar a Cursor y confirma la instalación en Cursor
  2. Abre Customize en la barra lateral, busca MyFinance en MCP servers y haz clic en Connect
  3. Inicia sesión con Google o con un código por correo y luego pregunta en el chat de Agent

Configuración manual: agrega esto a ~/.cursor/mcp.json

{
  "mcpServers": {
    "myfinance": {
      "url": "https://myfinance-mcp.com/mcp"
    }
  }
}

Guía completa para Cursor con primeros mensajes y soluciones.

codex mcp add myfinance \
  --url https://myfinance-mcp.com/mcp
codex mcp login myfinance

El segundo comando abre la página de inicio de sesión de MyFinance en tu navegador. Luego inicia codex y escribe /mcp para comprobar la conexión. En la extensión de Codex para IDE o en la app de escritorio de ChatGPT: MCP servers, luego Add server, Streamable HTTP, la misma URL y luego Authenticate. Codex está incluido en todos los planes de ChatGPT, también en Free y Go. Guía completa para Codex.

{
  "mcpServers": {
    "myfinance": {
      "url": "https://myfinance-mcp.com/mcp"
    }
  }
}

En Claude Code: claude mcp add --transport http myfinance https://myfinance-mcp.com/mcp
Windsurf usa serverUrl en lugar de url. Tu cliente se encarga del inicio de sesión OAuth automáticamente.

tendencia

Resúmenes y tendencias

Por categoría, comercio o mes; variaciones mes a mes calculadas en el servidor.

separar

Etiqueta cuentas y transacciones; una vista combinada para fundadores, con un corte limpio del negocio para tu contador.

tuyos

Exporta y conserva tus datos

Cada transacción en CSV y el resto de tu perfil (cuentas con historial de saldos, presupuestos, reglas de categorías) en un solo archivo, cuando quieras; borra tu cuenta y todo lo que contiene, al instante.

Preguntas frecuentes

Preguntas, respondidas

La versión corta. La página de privacidad (en inglés) tiene la larga.

¿Qué es MyFinance MCP?

Un control de gastos con IA, gratis, que funciona como servidor de Model Context Protocol. Llevas tus gastos, ingresos, presupuestos y patrimonio neto hablando con Claude, ChatGPT, Codex o Cursor: le dices a tu IA lo que gastaste, ella lo registra todo y el servidor hace las cuentas.

¿Qué es el Model Context Protocol (MCP)?

Un estándar abierto que permite a los asistentes de IA conectarse con herramientas externas. Un servidor MCP aporta capacidades concretas, aquí el control de las finanzas personales, que la IA puede usar durante una conversación. Piénsalo como un sistema de plugins para asistentes de IA.

¿Funciona con ChatGPT?

Sí, en ChatGPT en la web con Developer mode activado. El soporte completo, con registro de gastos incluido, está en ChatGPT Business, Enterprise y Edu. En Pro, OpenAI da a los servidores MCP personalizados acceso de solo lectura; su centro de ayuda no menciona Developer mode para Free, Go ni Plus, así que si no lo ves ahí, usa Codex (incluido en todos los planes de ChatGPT). En cualquier plan de ChatGPT, Free incluido, puedes usar MyFinance a través de Codex. Las dos configuraciones están en la guía de ChatGPT.

¿Qué clientes son compatibles?

Cualquier cliente MCP con OAuth 2.0 + PKCE: Claude (web, escritorio y móvil), Claude Code, ChatGPT (Business, Enterprise y Edu, en la web), Codex, Cursor, Windsurf y VS Code. Cada uno tiene una guía paso a paso en la página de instalación.

¿Necesito una cuenta de Google?

No. Al conectar, inicias sesión con Google o con un código de un solo uso enviado a cualquier dirección de correo; el primer inicio de sesión crea tu cuenta.

¿Es gratis?

Sí, gratis mientras esté en beta. Sin anuncios, sin tarjeta.

¿Mis datos son privados?

Tus datos están vinculados a tu cuenta y solo tú puedes acceder a ellos. Alojamiento en la UE, nada compartido con terceros, ningún importe en los logs, tokens de inicio de sesión guardados solo como hash unidireccional, y puedes exportar (las transacciones en CSV, el resto de tu perfil en un archivo) o borrarlo todo en cualquier momento.

¿Puede leer mi cuenta bancaria?

No le hace falta: funciona con cualquier banco mediante la importación de extractos. Exporta un CSV o un PDF, o haz una captura en la app del banco, y arrástralo al chat. Tu IA lo lee, el servidor importa cada fila, omite los duplicados y compara el total con el extracto. Si usas ZenMoney, puedes vincularlo para una sincronización de solo lectura. La sincronización bancaria directa en la UE y el Reino Unido, mediante open banking con licencia, es una beta cerrada, solo por invitación.

¿Qué pasa con los duplicados al importar un extracto?

El importador detecta las filas que ya registraste a mano y las fusiona en lugar de duplicarlas, y volver a importar el mismo extracto es seguro: las filas ya importadas se omiten y se informan.

¿Puedo separar lo personal del negocio?

Sí. Las cuentas y cada transacción llevan una etiqueta personal/negocio; cualquier informe se puede filtrar por ella, y la exportación CSV la incluye para tu contador.

¿Puedo alojarlo yo mismo?

Sí. Tiene licencia MIT y se ejecuta desde un Dockerfile con tu propio Postgres (Supabase sirve). El repositorio de GitHub incluye una guía de autoalojamiento.
